## 2. 可用于审查的结果

固定本地环境对照原始外部 CSS（A0）与最终内联版（A2），各 5 次：

| 场景 | A0 LCP 中位数 | A2 LCP 中位数 | 判断 |
| --- | ---: | ---: | --- |
| 冷访问 | 504 ms | 292 ms | 本地实验改善，减少一次阻塞样式请求 |
| 静态资源暖缓存 | 288 ms | 300 ms | 样本范围重叠，未证实稳定提速或退化 |

该对照为 Chromium、1365 × 768、CPU 4 倍降速、指定模拟网络；HTML 未压缩。暖访问要求重新获取 HTML，内联版每次多传 15,059 B 未压缩正文。上述结果不代表线上收益；也不与通知、字体或 gzip 实验的差值相加。

线上 gzip 是独立完成的交付：入口 JS 响应正文 206,248 → 88,544 B，CSS 16,045 → 4,715 B；编码、Vary 和解压后内容一致性通过。它减少网络字节，没有减少解压后的代码量，不证明执行或 LCP 同比例提速。
